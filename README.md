# Personal Notes and Reminder

A simple Android application for managing personal notes and reminders in one place.

This project was developed as a Project-Based Learning (PBL) academic project with the goal of providing users with a convenient way to create, manage, and organize personal notes and reminders.

## Features

- Create and manage personal notes
- Create reminders for important tasks and events
- View saved notes and reminders
- Receive notifications for reminders
- Persistent local data storage
- Simple and user-friendly interface

## Getting Started

### Prerequisites

Make sure the following are installed:

- Android Studio
- Android SDK
- Java Development Kit (JDK)
- Git

### Clone the Repository

```bash
git clone https://github.com/Sampad06/personal-notes-and-reminder.git
```

Navigate to the project directory:

```bash
cd personal-notes-and-reminder
```

### Open the Project

1. Open Android Studio.
2. Select **Open**.
3. Select the cloned `personal-notes-and-reminder` directory.
4. Allow Gradle to sync the project.
5. Connect an Android device or start an Android Emulator.
6. Click **Run**.

## Application Overview

### Notes

The application allows users to create and store personal notes for information they may need to access later.

### Reminders

Users can create reminders for tasks, events, or other activities. The application can notify users when a reminder becomes due.
